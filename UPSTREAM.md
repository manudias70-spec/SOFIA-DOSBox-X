# Upstream provenance

SOFIA-DOSBox-X is intended to be based on the upstream DOSBox-X project.

- Upstream project: https://github.com/joncampbell123/dosbox-x
- Upstream source must be pinned to a specific commit before modifications begin.
- Preserve upstream copyright notices, license files, and attribution.
- Review the exact licenses of bundled libraries and assets before redistributing binaries.
- Keep SOFIA-specific changes clearly documented and separated where practical.

No upstream source files have been imported into this repository yet. Do not describe this planning repository as a working DOSBox-X fork until that changes.
